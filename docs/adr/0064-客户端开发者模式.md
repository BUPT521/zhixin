# ADR-0064 客户端开发者模式

## 状态

已采纳。补充 [ADR-0063](0063-模型代理接入密钥.md) 的客户端入口，模型仍按 [ADR-0050](0050-客户端统一为知新服务.md) 通过知新服务调用。

## 日期

2026-11-25

## 背景

知新服务已经可以为脚本与第三方工具签发模型代理密钥，自建实例的用户也需要调整客户端连接的地址。切换实例后，登录会话与同步位置要按新实例重新建立，因此将实例配置和密钥管理放在默认关闭的开发者模式中。

## 决定

开发者模式按设备保存。开启后，用户可以修改知新服务实例地址，客户端只在目标实例的匿名就绪检查通过且 schema 匹配时保存地址。账号页显示当前地址，实例切换仍按账号空间的流程处理，见 [ADR-0056](0056-本机数据按账号分空间.md)。

登录用户可以通过现有的 `/v1/me/api-keys` 接口申请、查看和撤销模型代理密钥。申请时提交当前密码，完整密钥只在签发后展示一次，列表依靠名称与前缀辨认，撤销单把或全部密钥均需确认。

## 代价与边界

目标实例未就绪或版本不匹配时，用户需要先恢复服务或对齐版本才能切换，客户端继续连接原实例。关闭开发者模式只收起入口，已选实例与服务端签发的密钥继续生效，因此关闭开关不会退出账号或中断外部工具。

## 替代方案

账号页直接编辑地址会混合登录与实例切换，用户输入账号凭据前难以判断地址是否经过检查。将地址配置移到开发者模式后，登录只使用已保存的地址。

## 影响

- 页面流程见 [02 第 3.16 节](../02-产品与交互.md#316-账号与云同步)，授权与密钥作用域见 [ADR-0063](0063-模型代理接入密钥.md)。
