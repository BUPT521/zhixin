# ADR-0036 实例模型预算与账号用量分开

## 状态

已采纳。本条更新 [ADR-0031](0031-云端写入与托管模型的资源预算.md) 决定第 4 条的实例预算与结算规则，也补充 [ADR-0028](0028-服务端加固的默认拒绝与预算.md) 的预算口径。

## 日期

2026-11-20

## 背景

实例当天的预算原来按 `llm_usage` 里同一天所有账号的用量求和，而这张表随账号删除级联删除。用户删号会抹掉当天的账号用量行，实例预算因此重新腾出正好等于该账号当天用量的额度，而提供方那边已经发生的费用仍然存在，实例预算低估了实际支出；同一账号删号重开就能反复绕开实例上限。

并发原来只按账号限制，每个账号最多 `ZHIXIN_LLM_CONCURRENT_PER_USER` 个请求，请求体上限 8 MiB、非流式响应上限 32 MiB，两者乘以同时在途的账号数就是 Go 堆的潜在占用，实例预算管的是 token 而不是内存。nginx 每个来源地址 24 个连接、站点合计 128 个连接，账号数量足够多时这条连接限制换算成的内存仍然远超一台 1682 MB 的机器。嵌入请求还会把一次输入拆成多批并发读取，每批各自读到响应上限才检查合计，四批同时读满时内存是上限的四倍。

## 决定

1. 实例当天的模型用量单独记在 `llm_instance_usage`，只有自然日与 token 数，不与账号关联；预留与结算在同一个事务里同时更新账号用量与实例账本，删号与清空云端数据都不减少实例账本，实例预算因此记录的是提供方已经计费的部分。
2. 模型代理增加实例级字节预算 `ZHIXIN_LLM_MAX_INSTANCE_BYTES`，默认 256 MiB。请求体在读进内存之前按声明长度的两倍预留，因为转发前要替换模型名并重新编码一份正文；长度未知或超过请求体上限时按上限预留。非流式响应在读取之前按 `ZHIXIN_LLM_MAX_RESPONSE_BYTES` 预留，嵌入请求按响应上限的两倍预留，因为各批正文合并之后还要再渲染一份完整响应。占不到预算时在写出任何内容之前返回 429，不排队等待。
3. 一次嵌入请求拆成多批并发读取时，各批共享同一份响应上限，合计到达上限之后按响应过大处理，不再先读进内存再相加。

## 代价与边界

字节预算只约束单个进程，多实例部署时每个进程各有一份，实例级的总量要按进程数相乘。占不到预算的请求即使账号额度充足也会得到 429，客户端要按 `Retry-After` 重试，高峰时表现为短暂失败而不是排队等待。按最坏情况预留会让大请求体的并发变小：默认配置下非流式聊天最多占 48 MiB、嵌入请求最多占 64 MiB，预算 256 MiB 时同时在途的这两类请求分别不超过五个和四个，流式聊天只占请求体那部分。字节数是估算而不是精确计量，合并嵌入正文与序列化响应时的临时副本仍可能让单个请求短暂超过预留一点，预算限制的是数量级而不是毫秒级的峰值。

实例账本按自然日保留，本项目没有为它写清理任务，与 `llm_usage` 一样随库增长；每天一行，实际占用可以忽略。

## 替代方案

继续按 `llm_usage` 汇总实例用量，代价是删号重新腾出预算，与预算要防止的滥用正好相悖。删号时保留该账号的用量行，代价是“删号即清理云端数据”的承诺出现例外，账号标识也会在删除之后继续留在库里。用 `llm_route_usage` 的汇总代替账本，它是每次尝试结束之后补记的事后记账，并发请求互相看不见已经预留的额度，[ADR-0028](0028-服务端加固的默认拒绝与预算.md) 已经否掉这条做法。按账号数乘以固定的单账号内存估算并发，请求体从几 KB 到 8 MiB 都有，按数目估算挡不住大请求体，也拦不住同一账号的多个请求。

## 影响

- [服务端说明](../../server/README.md)记录配置项、429 的触发条件与两份用量表的区别。
- `server/internal/store/schema.sql` 增加 `llm_instance_usage`，`internal/store/queries/quota.sql` 增加按差额调整账本的语句，PostgreSQL 与内存两种实现同步修改（[store/pg/quota.go](../../server/internal/store/pg/quota.go)、[llmproxy/quota.go](../../server/internal/llmproxy/quota.go)）。
- `server/internal/llmproxy` 增加实例字节预算（[membudget.go](../../server/internal/llmproxy/membudget.go)）与嵌入批次的共享额度，请求入口从按账号的并发名额扩展为并发名额加字节预算。
- [运维手册](../../server/运维手册.md)的常用操作保留按账号查用量的语句，实例账本可以按天直接查表。
