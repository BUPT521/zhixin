# 知新 · 一个懂你的学习搭子

> 知新是一个懂你的学习搭子，用户可以从一道题、一次讨论或一份材料直接开始，既能解决独立问题，也能沿着课程、材料或目标系统学习，并在再次返回时接着上次的内容和进度继续。

## 产品方向

知新面向大学生和有自主学习需求的人。用户可以随手问一个概念、拍一道题，也可以从教材、课件或明确目标开始系统学习，两种方式共用原文、讨论与学习记录。此前的讨论可以成为系统学习的起点，系统学习中的临时问题也可以单独处理，讨论后回到原来的材料与进度。

课程和目标用于组织确实相关的内容，独立问题可以保留在记录中。搭子根据材料出处、上次的尝试和仍未解决的问题提供提示、解释或检查；当用户希望继续某项学习时，再结合期限、课表与可用时间建议下一项活动。

## 数据与用户控制

学习记录默认保存在本机，可以离线查看、导出与恢复，调用模型时只发送当次所需内容。账号是可选项：登录之后，记录可以备份并同步到项目组自建的服务端，模型也可以改用服务端代理，不登录时应用照常在本机运行，决定见 [ADR-0008](docs/adr/0008-取消单机边界引入账号同步与模型代理.md)。记忆带来源和适用范围，用户可以查看、纠正或删除；AI 执行的变更有回执和撤销入口，涉及删除原始记录或调整固定安排时由用户决定。

## 技术栈与开发环境

| 项 | 选择 |
|---|---|
| 客户端 | Flutter 3.50.0（Dart 3.14.0），本期只交付 Android；版本固定在 [ci.yml](.github/workflows/ci.yml) 的 `FLUTTER_VERSION` |
| 界面组件 | Forui 0.28.0 承担页面骨架、按钮、表单、列表、对话框、提示、进度与主题；底部面板与日期时间选择用 `material_ui` 的对应控件，基础控件、路由、Markdown 与本地化也用 `material_ui`，图标统一用 Lucide（`forui_lucide`） |
| 最低系统 | Android 11（API 30）；只出 arm64 包，不兼容 32 位设备 |
| 本地数据 | SQLite 单文件（drift，连接使用随包的 sqlite3），业务表、提交历史与附件同库，表结构与当前版本见 [01](docs/01-ER数据模型.md) |
| 模型 | 只有知新服务一种来源，即登录之后经服务端模型代理调用，模型名与上下文上限可在设置页填写；不登录时回答按本地兜底给出，见 [ADR-0050](docs/adr/0050-客户端统一为知新服务.md) |
| 服务端 | Go 1.27 单个可执行文件 `zhixin-api`，标准库 `net/http`；账号、提交序列、整库备份、附件与模型代理按契约实现，元数据使用 PostgreSQL，备份和附件字节放 S3 兼容的对象存储，第一套实例用阿里云 OSS，本地联调可用内存或本机目录，限制见 [server/README](server/README.md)，取舍见 [ADR-0009](docs/adr/0009-API后端采用Go与分层框架.md) 与 [ADR-0015](docs/adr/0015-服务端引入代码生成与限流依赖.md) |
| 构建 | JDK 21 + Android SDK 36，命令 `flutter build apk --debug`（内测包用 `--release`），见 [app/README](app/README.md) |

应用代码在 `app/` 目录，先 `cd app`，再执行 `flutter pub get` 和 `flutter run` 就能装到真机上。CI 配置见 [ci.yml](.github/workflows/ci.yml)：代码推送和 PR 都会跑生成代码核对、格式检查、`flutter analyze` 与 `flutter test`，纯文档的提交跳过这几项；`main` 的 push 和每个 PR 都会构建 debug APK。正式包在 Actions 里手动运行“CI 与发版”生成。服务端在 `main` 收到 `server/` 的改动后自动部署，检查、回滚与手工发布见 [deploy-server.yml](.github/workflows/deploy-server.yml) 与[运维手册](server/运维手册.md#49-自动部署与回滚)。

## 文档维护

- 先改“唯一真相”：定义改 00，字段改 01，页面与验收改 02，分工与节点改 03；其他文档只引用，不另造数字。
- 有取舍才记一条决定：单一领域写进对应文档的一句话或提交正文，跨模块的写一条 ADR，规则见 [AGENTS 第 3 节](AGENTS.md)。
- 方案、审查与工作单一类的文档，开头写明当前状态（现行口径、背景材料或在办任务），完成或失效时改开头这一句；本文的文档表只登记用途与状态，口径以各篇正文为准。
- 开发阶段（1.0.0 之前）不承诺向下兼容，破坏性重构与数据重建按 [ADR-0001](docs/adr/0001-开发阶段不向下兼容.md) 执行。
- 写文档的口径（中文长句、全角标点、链接可打开、表格不错位）见 [AGENTS 第 6 节](AGENTS.md)，推送前删掉临时文件。
